# v4.3.35 English TEST — iPhone Responsive Test

This build is for iPhone/iOS Safari compatibility testing only.

## Check on iPhone
1. Home: scroll to the bottom and confirm the bottom menu does not cover content.
2. Officer: confirm Save, Edit Progress, MAX and Reset buttons fit cleanly.
3. Open Edit Officer Progress:
   - Star and Officer Level controls should fit the screen.
   - Skill Strands should be compact rather than excessively tall.
   - Training and Save/MAX/Cancel controls must remain reachable.
4. Settings: confirm bottom content can be scrolled above the navigation.
5. Rotate portrait/landscape if available and confirm there is no horizontal page overflow.

## Regression check
Android and PC should look and behave the same as the existing v4.3.35 LIVE build because the new layout rules are scoped to iOS Safari.

This TEST does not alter Officer calculation logic.
